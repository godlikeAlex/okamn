DOM — это объектное представление HTML-документа в виде дерева, которое создаёт браузер. Каждый тег становится узлом, и через DOM API JavaScript может находить элементы, менять их содержимое и атрибуты, добавлять и удалять узлы и подписываться на события.

Важно, что DOM — это **не сам HTML и не часть JavaScript**, а API браузера. Изначально DOM строится из HTML, но после изменений через JavaScript текущее DOM-дерево уже может отличаться от исходной разметки.
