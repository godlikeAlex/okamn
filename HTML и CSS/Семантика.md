Семантическая вёрстка — это использование тегов **по их смыслу**, а не только по внешнему виду. Например, для навигации использовать `nav`, для основной части страницы — `main`, для самостоятельного материала — `article`, а для действия — `button`, а не кликабельный `div`.

Это делает структуру страницы понятнее разработчикам и поисковым системам, а главное — помогает скринридерам и другим вспомогательным технологиям правильно интерпретировать интерфейс. При этом семантический тег не привязывает нас к конкретному внешнему виду: его всё равно можно стилизовать через CSS.
