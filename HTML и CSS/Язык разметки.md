HTML — это язык разметки, который описывает **структуру и смысл содержимого страницы**: заголовки, текст, ссылки, формы и другие элементы. Это не язык программирования, потому что сам по себе HTML не содержит логики и алгоритмов.

Браузер получает HTML, разбирает его и строит на его основе DOM-дерево. Если совсем коротко, HTML отвечает за структуру, CSS — за внешний вид, а JavaScript — за поведение страницы.
