`z-index` управляет порядком наложения элементов по оси Z, но сравнивается не глобально по всей странице, а **внутри stacking context**, то есть контекста наложения.

Новый stacking context создают, например, позиционированный элемент с `z-index`, `opacity` меньше единицы, `transform` или `isolation: isolate`. Дочерний элемент не может своим большим `z-index` выйти из контекста родителя и перекрыть элемент из более высокого внешнего контекста.

Поэтому если `z-index: 9999` не работает, я сначала проверяю не само число, а контексты наложения у элемента и его родителей.
