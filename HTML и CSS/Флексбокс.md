Для включения Flexbox задаём контейнеру `display: flex`. `flex-direction` определяет главную ось, `justify-content` выравнивает элементы вдоль неё, а `align-items` — по поперечной оси. `flex-wrap` разрешает перенос на новые строки, а `gap` задаёт расстояние между элементами.

У дочерних элементов основные свойства — `flex-grow`, `flex-shrink` и `flex-basis`: они определяют, как элемент растёт, сжимается и какой базовый размер имеет. Сокращение `flex` задаёт эти значения одной записью. Для отдельного элемента также можно переопределить выравнивание через `align-self`.

Важно каждый раз смотреть на направление главной оси: при `flex-direction: column` смысл `justify-content` и `align-items` визуально меняется вместе с осями.
