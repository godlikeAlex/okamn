`form` объединяет поля и описывает отправку данных. У каждого поля обычно должны быть понятный `name`, чтобы значение попало в данные формы, и связанный `label`. Связать их можно через `for` у `label` и `id` у поля либо вложить поле внутрь `label`.

Тип `input` лучше выбирать по смыслу: например, `email`, `number`, `date` или `password`. Это даёт встроенную проверку, подходящую клавиатуру на мобильном и дополнительную семантику. Для ограничений есть `required`, `min`, `max`, `minlength`, `maxlength` и `pattern`.

У `button` внутри формы тип по умолчанию — `submit`, поэтому для обычной кнопки лучше явно указывать `type="button"`.

Встроенная валидация улучшает пользовательский опыт, но **не заменяет проверку на сервере**, потому что клиентские ограничения можно обойти.
