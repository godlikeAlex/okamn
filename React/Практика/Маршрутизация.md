Клиентская маршрутизация меняет URL и React-дерево без полной перезагрузки документа. React Router подписывается на History API, сопоставляет текущий location с конфигурацией маршрутов и рендерит нужную ветку.

`Link` выполняет навигацию через router, сохраняя SPA-поведение и доступность обычной ссылки. Параметры пути и query читаются через API роутера, а вложенные маршруты позволяют собирать layout с дочерним outlet.

Важные практические задачи — страница 404, редиректы, защита маршрутов, восстановление скролла и code splitting по страницам. Проверку прав нельзя оставлять только на клиентском маршруте: сервер всё равно обязан авторизовать запрос.

Современные data routers также связывают маршрут с загрузкой данных, actions и обработкой ошибок, чтобы не собирать эту логику вручную в Effects каждого экрана.
