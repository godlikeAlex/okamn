`useSyncExternalStore` — хук для безопасной подписки React на store или изменяемый источник вне React. Его чаще используют авторы библиотек и интеграций с браузерными API, а не вместо обычного `useState` в каждом компоненте.

Хук принимает `subscribe`, который возвращает отписку, и `getSnapshot`, возвращающий неизменяемый snapshot текущего состояния. Пока store не изменился, повторный `getSnapshot` должен возвращать значение, равное предыдущему по `Object.is`.

Для SSR можно передать `getServerSnapshot`, чтобы серверный и первый клиентский результаты совпали при hydration.

Главная ценность — согласованное чтение внешнего mutable store, в том числе при конкурентном рендеринге. Redux, Zustand и другие библиотеки обычно скрывают подобную интеграцию внутри своих React-bindings.
