У классового компонента есть фазы mount, update и unmount.

При mount вызываются `constructor`, `render`, затем `componentDidMount`. При update — `render`, после commit `componentDidUpdate`; перед render можно повлиять на оптимизацию через `shouldComponentUpdate`. При удалении вызывается `componentWillUnmount` для очистки.

`getSnapshotBeforeUpdate` позволяет прочитать DOM непосредственно перед commit и передать значение в `componentDidUpdate`. `getDerivedStateFromProps` существует, но нужен редко: производное значение обычно лучше вычислять во время render.

В функциональном компоненте нет точного соответствия каждому lifecycle. `useEffect` описывает один процесс синхронизации вместе с cleanup, `useLayoutEffect` работает до paint, а render остаётся обычным вызовом функции.
