Error Boundary перехватывает ошибку render, конструктора или lifecycle-метода в дочернем React-дереве и показывает fallback вместо падения всего интерфейса.

Обычная реализация остаётся классовой: `static getDerivedStateFromError` обновляет state для fallback, а `componentDidCatch` получает ошибку и информацию о дереве для логирования. В приложении можно использовать готовую библиотечную обёртку.

Boundary не ловит ошибки обработчиков событий, обычного асинхронного callback, серверного рендера и ошибку внутри самого Boundary. Такие сценарии обрабатываются в своём месте через `try/catch`, Promise или механизм framework.

Boundary нужно располагать по смысловым участкам, чтобы ошибка одного виджета не уронила всю страницу. Для повторной попытки его состояние можно сбросить через API обёртки или новый `key`.
