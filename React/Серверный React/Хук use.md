API `use` читает ресурс во время render. Если передать Promise, React приостановит компонент до его завершения: ближайший `Suspense` покажет fallback, а ошибка уйдёт в Error Boundary. Если передать Context, `use` вернёт его текущее значение.

В отличие от обычных хуков, `use` можно вызывать внутри условия или цикла, но только из компонента или кастомного хука. Его нельзя оборачивать в `try/catch` — для результата используются Suspense и Error Boundary.

Promise должен быть стабильным и обычно создаётся framework, кешем или на сервере и передаётся компоненту. Создание нового Promise прямо во время каждого клиентского render приводит к повторным приостановкам и предупреждениям.

`use` не является универсальной заменой `await`: он интегрирует чтение ресурса именно с React-рендерингом.
