Action — функция, которая выполняет обновление данных внутри Transition. Она может быть асинхронной, а React помогает связать результат, pending-состояние, формы и optimistic UI.

`useActionState` принимает Action и начальное состояние и возвращает текущее состояние, функцию запуска и `isPending`. Action получает предыдущее состояние и payload и возвращает следующее, поэтому удобно обрабатывать результат отправки формы и серверные ошибки.

Функцию можно передать в `action` формы или `formAction` кнопки. `useFormStatus` из `react-dom` читает статус ближайшей родительской формы и позволяет, например, отключить кнопку отправки без прокидывания pending через props.

Action может быть клиентской или Server Function в framework. Этот API не отменяет обработку ошибок, валидацию и защиту от повторных запросов на сервере.
