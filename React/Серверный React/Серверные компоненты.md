Server Components выполняются в серверной среде, а их код не входит в клиентский JavaScript-бандл. Они могут быть `async`, читать базу, файловую систему или внутренний API рядом с данными.

В них нельзя использовать state, Effects, обработчики событий и браузерные API, потому что компонент не живёт в браузере. Результат передаётся клиенту в специальном сериализованном формате React, а не просто как готовый HTML.

Client Components поддерживают интерактивность, state и хуки. Важно, что слово client не означает «вообще не рендерится на сервере»: framework может предварительно отрендерить такой компонент в HTML, но его код также отправится браузеру для hydration.

Server Components дополняют SSR: RSC отвечает за разделение кода и данных между средами, а SSR — за генерацию начального HTML.
