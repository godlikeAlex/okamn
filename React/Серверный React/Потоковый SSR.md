Streaming SSR — это отправка HTML частями по мере готовности вместо ожидания полного рендера страницы. Сервер сначала может отдать shell приложения и fallback ближайших `Suspense`, а затем досылать готовые участки.

В Node.js для этого используется `renderToPipeableStream`, а в средах с Web Streams — `renderToReadableStream`. Обычно эти API вызывает framework.

Преимущество — более ранний первый контент и отсутствие блокировки всей страницы одним медленным участком. `Suspense` задаёт границы, в которых части интерфейса могут появляться независимо.

На клиенте React может гидратировать участки выборочно и отдавать приоритет тому, с чем пытается взаимодействовать пользователь. Streaming ускоряет доставку HTML, но не отменяет загрузку JavaScript для интерактивных Client Components.
