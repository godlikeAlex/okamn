При CSR сервер обычно отдаёт HTML-контейнер и JavaScript, а интерфейс строится в браузере после загрузки и выполнения бандла. Это проще для чистой SPA, но пользователь позже видит содержимое, а поисковому роботу приходится полагаться на выполнение JavaScript.

При SSR React формирует HTML на сервере и отправляет уже готовое содержимое. Пользователь раньше видит страницу, но для интерактивности всё равно нужен клиентский JavaScript.

Hydration — процесс, в котором `hydrateRoot` создаёт React-дерево поверх существующего серверного DOM и подключает обработчики. React старается переиспользовать HTML, а не создать его заново.

`createRoot` используют для клиентского корня без готовой React-разметки. Если применить его к серверному HTML, React очистит содержимое и построит DOM заново.
