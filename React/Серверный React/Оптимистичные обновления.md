`useOptimistic` позволяет сразу показать ожидаемый результат операции, пока настоящий запрос ещё выполняется. Например, добавить сообщение в список до подтверждения сервера.

Хук получает подтверждённое базовое значение и возвращает временное optimistic-состояние и функцию обновления. Для сложного изменения можно передать reducer, который объединяет текущее состояние с optimistic payload.

Обновление вызывается внутри Action или Transition. Когда операция завершилась, React снова использует актуальное базовое значение; при ошибке временное состояние откатывается, а интерфейс должен показать пользователю причину.

Optimistic UI не заменяет серверный источник истины. Нужно продумать конфликты, повторную отправку и порядок нескольких одновременных изменений.
