Директива `"use client"` ставится в начале модуля и создаёт границу клиентского графа. Сам файл и модули, которые он импортирует, становятся частью клиентского бандла.

Поэтому границу лучше держать как можно ниже: оставить загрузку данных и статическую разметку на сервере, а маленький интерактивный участок сделать Client Component.

Props через границу должны быть сериализуемыми. Обычную функцию или подключение к базе передать клиенту нельзя; отдельный механизм Server Functions имеет собственные правила.

Client Component не может напрямую импортировать Server Component. Но серверный родитель может передать уже созданный Server Component в `children` клиентской обёртки — так серверный контент не втягивается в клиентский граф.
