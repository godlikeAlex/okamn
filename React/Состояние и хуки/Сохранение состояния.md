React привязывает state не к JSX-тегу и не к вызову функции, а к позиции компонента в React-дереве. Пока в той же позиции остаётся компонент того же типа и с тем же key, состояние сохраняется.

Если тип или key меняется, старый компонент размонтируется, а новый создаётся с начальным состоянием. Поэтому key можно использовать не только в списках, но и для намеренного сброса формы или другого поддерева.

Важно не объявлять компонент внутри другого компонента без необходимости. На каждом рендере будет создаваться новая функция-типа, и React станет сбрасывать состояние вложенного компонента.

То, что JSX визуально находится в той же ветке `if`, само по себе не гарантирует сохранение — важны итоговая позиция, тип и key.
