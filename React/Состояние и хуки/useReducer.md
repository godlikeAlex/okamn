`useReducer` — альтернатива `useState` для состояния с несколькими связанными переходами. Он принимает reducer и начальное состояние и возвращает текущий state и `dispatch`.

Через `dispatch` отправляется action с описанием произошедшего события, а reducer по предыдущему состоянию и action вычисляет новое. Reducer должен быть чистым и не мутировать state.

Главное преимущество — логика переходов собрана в одном месте, а компоненты только сообщают, что произошло. Это удобно для сложной формы, пошагового процесса или state machine.

`useReducer` сам по себе не делает код быстрее и не создаёт глобальное состояние. Для пары независимых простых значений `useState` обычно понятнее.
