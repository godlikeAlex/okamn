`useState` добавляет компоненту состояние и возвращает значение текущего рендера и setter. Setter не меняет уже выполняющийся render, а ставит обновление в очередь и просит React отрендерить компонент снова.

Каждый render получает собственный **снимок состояния**. Поэтому после `setCount(count + 1)` переменная `count` в текущем обработчике не изменится. Если новое значение зависит от предыдущего, используют функциональное обновление: `setCount(value => value + 1)`.

Объекты и массивы обновляют иммутабельно, создавая новую ссылку. Если React сравнит новое и старое значение через `Object.is` и они равны, повторный рендер обычно будет пропущен.

Для дорогого начального вычисления в `useState` передают функцию — React вызовет её только при инициализации компонента.
