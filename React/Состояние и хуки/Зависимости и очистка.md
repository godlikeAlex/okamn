В массив зависимостей Effect входят все reactive-значения, прочитанные внутри: props, state и функции или переменные, созданные в компоненте. React сравнивает зависимости между рендерами через `Object.is`.

Без массива Effect запускается после каждого commit, с пустым массивом — после первого mount, а с зависимостями — когда хотя бы одна изменилась. Пустой массив не означает «выполни один раз вообще»: в StrictMode development React дополнительно проверяет setup и cleanup.

Cleanup выполняется перед следующим setup с изменившимися зависимостями и при размонтировании. В нём снимают подписку, очищают таймер, отключают соединение или помечают устаревший запрос.

Не стоит подавлять `exhaustive-deps`, чтобы заставить Effect запускаться реже. Сначала лучше изменить структуру кода: перенести действие в handler, вынести стабильное значение или убрать сам Effect.
