`useRef` возвращает стабильный объект с полем `current`, который сохраняется между рендерами. Изменение `current` не вызывает повторный рендер, поэтому ref подходит для данных, не влияющих на отображение.

Основные случаи — получить DOM-узел, сохранить ID таймера, экземпляр сторонней библиотеки или другое изменяемое значение между рендерами.

Если значение должно появиться в UI, нужен state. Ref не должен становиться обходным хранилищем состояния, потому что React не узнает об изменении.

Читать или менять `ref.current` во время рендера обычно нельзя: это нарушает чистоту. Исключение — предсказуемая одноразовая инициализация собственного объекта.
