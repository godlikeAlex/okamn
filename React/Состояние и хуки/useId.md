`useId` генерирует стабильный ID, который подходит для связей доступности: `label` с `input`, `aria-describedby` и других ARIA-атрибутов.

Он согласован с SSR и hydration: при одинаковом React-дереве сервер и клиент получают совместимые идентификаторы. Это надёжнее, чем `Math.random()` или глобальный счётчик.

`useId` не предназначен для ключей списка. Key должен приходить из самих данных и описывать идентичность элемента, а ID хука зависит от положения компонента в дереве.

Один вызов можно использовать как префикс для нескольких связанных элементов.
