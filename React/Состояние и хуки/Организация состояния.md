Я стараюсь хранить минимальное состояние и иметь один источник истины. Если значение можно вычислить из props и другого state во время рендера, отдельно сохранять его обычно не нужно.

Связанные данные лучше обновлять согласованно, но не обязательно складывать всё в один объект. Противоречащие друг другу флаги часто лучше заменить одним статусом, например `"idle" | "loading" | "success" | "error"`.

Если нескольким компонентам нужны одни данные, state поднимают к ближайшему общему родителю и передают вниз. Это называется lifting state up.

Копировать prop в state стоит только когда это осознанное начальное значение. Иначе локальная копия перестанет обновляться вместе с prop и появятся два источника истины.
