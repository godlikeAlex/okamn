Каждый render создаёт новый снимок props и state. Callback замыкается на значения того рендера, в котором был создан. Если долгоживущий таймер, подписка или Effect продолжает использовать старый callback, возникает stale closure.

Для обновления state от предыдущего значения помогает функциональный setter. Если Effect должен пересоздаваться при изменении значения, его добавляют в зависимости. Для изменяемого значения, которое не влияет на UI, иногда используют ref.

В актуальном React есть `useEffectEvent`: он позволяет вынести не реактивную часть Effect и при вызове читать последние committed props и state, не переподключая сам Effect. Это не способ спрятать настоящую зависимость и вызывать Effect Event можно только из Effect-логики.

Главное — не лечить stale closure пустым массивом зависимостей. Нужно явно решить, должна логика реагировать на изменение или только читать последнее значение.
