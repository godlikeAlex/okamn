Ref можно передать DOM-элементу, чтобы родитель вызвал `focus`, измерил размер или использовал браузерный API. Начиная с React 19 функциональный компонент может получать `ref` как prop. В React 18 и старше для этого использовали `forwardRef`.

Если не хочется отдавать родителю весь DOM-узел, `useImperativeHandle` позволяет вернуть ограниченный объект, например только методы `focus()` и `clear()`.

Это escape hatch для императивных действий, а не основной способ общения компонентов. Данные и события по-прежнему лучше передавать через props, потому что ref обходит декларативный поток React.

Ref назначается во время commit. При размонтировании DOM-ref снова становится `null`.
