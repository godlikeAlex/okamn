`useEffect` нужен для синхронизации компонента с **внешней системой**: подпиской, таймером, DOM API, сетевым соединением или сторонним виджетом.

Effect запускается после commit. Функция setup создаёт синхронизацию, а возвращённый cleanup должен её отменить. На следующем запуске React сначала выполнит cleanup со старыми значениями, а затем setup с новыми; при размонтировании останется только cleanup.

Effect выполняется только на клиенте. Он не должен быть универсальным способом организовывать поток данных внутри React — вычисления из props и state обычно делаются прямо во время рендера, а пользовательские действия обрабатываются в event handler.

Запрос в Effect допустим, но нужно учитывать отмену, гонки, кеширование и повторную загрузку. В приложении с роутером или data-библиотекой загрузку часто лучше отдать им.
