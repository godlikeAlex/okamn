Если значение можно получить из props и state, его вычисляют во время рендера, а не сохраняют через Effect. Например, `fullName` не требует отдельного state и Effect из `firstName` и `lastName`.

Логика, вызванная конкретным действием пользователя, должна быть в обработчике события. Effect нужен, когда компонент уже оказался на экране и должен синхронизироваться с чем-то внешним.

Для сброса всего состояния при смене сущности можно изменить `key`, а не запускать Effect с несколькими setter. Дорогой чистый расчёт при необходимости мемоизируют через `useMemo`.

Лишний Effect часто создаёт дополнительный render: сначала показывается состояние, затем Effect вычисляет другое и запускает обновление. Чем меньше таких цепочек, тем проще поток данных.
