Хуки нужно вызывать на верхнем уровне React-компонента или кастомного хука. Их нельзя помещать в обычный `if`, цикл, callback или вызывать после условного `return`.

React связывает состояние хуков с **порядком вызова**, поэтому этот порядок должен быть одинаковым на каждом рендере. Если условие нужно, его обычно переносят внутрь хука либо выделяют отдельный компонент.

Хуки вызывают только из React-функций, а кастомный хук называют с `use`, чтобы линтер мог проверить правила.

Отдельное исключение — API `use`: его можно вызывать в условиях и циклах, но всё равно только внутри компонента или хука и не внутри `try/catch`.
