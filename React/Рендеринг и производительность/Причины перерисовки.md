Компонент рендерится при изменении собственного state, при обновлении родителя, при изменении читаемого context или внешнего store, на который он подписан.

По умолчанию рендер родителя вызывает render его детей, даже если визуально их props не изменились. `React.memo` может пропустить такой вызов при равных props, но собственный state и context всё равно обновят компонент.

Изменение `ref.current` рендер не запускает. Вызов setter с тем же значением по `Object.is` обычно позволяет React пропустить обновление.

Смена `key` — не обычная перерисовка, а размонтирование старого компонента и создание нового со сброшенным state.
