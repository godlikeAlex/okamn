`Suspense` показывает fallback, пока вложенное поддерево не готово к рендеру. Компонент приостанавливается, когда во время render читает поддерживаемый асинхронный ресурс, например lazy-компонент, Promise через `use` или данные из Suspense-совместимого framework.

Обычный запрос, запущенный в `useEffect`, Suspense автоматически не видит. Оборачивать произвольный Promise вручную без поддержки framework или библиотеки тоже не стоит считать публичным универсальным API.

Границы Suspense позволяют управлять последовательностью раскрытия интерфейса. Вместе с transition React может сохранить уже показанный контент вместо резкой замены на fallback.

Suspense не является Error Boundary: Promise обрабатывает Suspense, а ошибку — ближайший Error Boundary.
