Virtual DOM — условное название дерева React-элементов в памяти, которое описывает желаемый интерфейс. При обновлении React строит новое описание и в процессе reconciliation сопоставляет его с предыдущим.

React использует эвристики. Если тип элемента изменился, старое поддерево размонтируется и строится новое. Если тип совпадает, React сохраняет соответствующий узел и состояние, обновляя изменившиеся props. Дети списков сопоставляются по `key`.

После сверки в commit применяются нужные изменения к реальному DOM. Цель не в том, чтобы всегда найти математически минимальный diff, а в том, чтобы предсказуемо и достаточно быстро обновить UI.

Повторный вызов компонента не означает обязательное изменение DOM: результат может оказаться тем же.
