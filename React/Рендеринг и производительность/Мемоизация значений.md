`useMemo` кеширует результат вычисления между рендерами, пока зависимости равны по `Object.is`. Его используют для действительно дорогого расчёта либо чтобы сохранить ссылку на объект, от которой зависит другая мемоизация.

`useCallback` кеширует саму функцию. По сути это удобная форма `useMemo(() => callback, dependencies)`. Он полезен, когда callback передаётся в мемоизированный компонент или является зависимостью другого хука.

Оба хука тоже требуют работы: нужно создать функцию, сохранить зависимости и сравнить их. Если потребитель не использует стабильность ссылки, `useCallback` ничего не ускоряет.

На мемоизацию нельзя опираться для корректности — это оптимизация. React Compiler способен автоматически мемоизировать многие значения и компоненты, но ручные хуки остаются способом точного контроля и поддержки проектов без компилятора.
