`useTransition` помечает обновление state как несрочное. React может выполнять его в фоне и прерывать ради более важного обновления. Хук возвращает `isPending` и `startTransition`, поэтому подходит, когда мы контролируем setter, например при переключении тяжёлой вкладки.

Transition нельзя использовать для state контролируемого input: ввод должен обновляться сразу. Также она не откладывает вызов функции — callback `startTransition` выполняется немедленно, меняется приоритет запланированных обновлений.

`useDeferredValue` принимает уже полученное значение и возвращает его отложенную версию. Срочная часть UI показывает новое значение, а тяжёлое поддерево некоторое время может использовать предыдущее.

У этих API нет фиксированной задержки как у debounce. Они управляют приоритетом render и не уменьшают количество сетевых запросов сами по себе.
