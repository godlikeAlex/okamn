Fiber — внутренняя архитектура React, в которой каждому элементу дерева соответствует fiber-узел, а работа над обновлением разбивается на небольшие единицы.

Раньше рекурсивный render выполнялся целиком и не мог уступить управление. Fiber позволяет React планировать обновления по приоритету, приостанавливать менее срочную render-работу, обработать ввод пользователя и затем продолжить или пересчитать результат.

Для этого React хранит текущее committed-дерево и строящееся work-in-progress дерево. Связи `child`, `sibling` и `return` позволяют обходить работу итеративно.

Прерываемой является render phase. Commit с изменением DOM остаётся синхронным и атомарным.
