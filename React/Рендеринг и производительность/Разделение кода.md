Code splitting — разделение общего JavaScript-бандла на чанки, которые загружаются по необходимости. Это уменьшает объём кода при первом открытии страницы.

Динамический `import()` возвращает Promise и даёт сборщику точку разделения. `lazy(() => import(...))` превращает такой модуль в React-компонент, а ближайший `Suspense` показывает fallback до его загрузки.

Чаще всего код разделяют по маршрутам и тяжёлым редко используемым функциям. Делить каждый маленький компонент невыгодно: растут накладные расходы, количество запросов и вероятность увидеть fallback.

`lazy` кеширует Promise и загруженный модуль. По умолчанию он ожидает компонент в `default export`.
