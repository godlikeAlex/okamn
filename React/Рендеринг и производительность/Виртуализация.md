Виртуализация — это рендер только видимой части большого списка вместо тысяч элементов сразу. Так уменьшаются количество DOM-узлов, расход памяти и стоимость layout и paint.

Контейнер сохраняет размер полного списка, чтобы скроллбар выглядел нормально. По позиции прокрутки рассчитывается окно элементов плюс небольшой overscan сверху и снизу; ушедшие элементы переиспользуются или удаляются.

Для React есть библиотеки TanStack Virtual и react-window. Самостоятельная реализация усложняется при динамической высоте строк, изменении размера контейнера, восстановлении позиции и доступности.

Минусы — отсутствующие в DOM элементы не находятся обычным поиском страницы, а управление фокусом и измерениями требует дополнительной логики.
