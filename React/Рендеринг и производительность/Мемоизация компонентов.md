`React.memo` возвращает мемоизированную версию функционального компонента. Когда родитель рендерится, React может пропустить render ребёнка, если каждый prop равен предыдущему по `Object.is`.

Новый объект, массив или функция считается изменившимся prop, даже если содержимое выглядит одинаково. Можно передать свой comparator, но он должен сравнить все props, включая функции, и иногда обходится дороже самого render.

`PureComponent` — классовый аналог: он поверхностно сравнивает и props, и state через реализацию `shouldComponentUpdate`.

Мемоизация не блокирует обновление собственного state или context и является оптимизацией, а не гарантией поведения. Применять её стоит после профилирования либо для заведомо тяжёлого стабильного поддерева.
