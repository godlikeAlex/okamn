Компонент должен быть чистой функцией рендера: при одинаковых props, state и context возвращать одинаковое описание UI и **не менять внешние значения во время рендера**.

В render нельзя отправлять запрос, менять DOM, запускать таймер или мутировать полученный объект. React может вызвать компонент несколько раз, прервать результат или вообще не выполнить commit, поэтому побочный эффект из render становится непредсказуемым.

Обработчики событий выполняются в ответ на действие пользователя, а синхронизация с внешней системой обычно размещается в Effect. Создавать и изменять локальные значения, появившиеся внутри текущего рендера, безопасно — они не существовали до вызова компонента.

Чистота особенно важна для StrictMode, конкурентного рендеринга и React Compiler.
