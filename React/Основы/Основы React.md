React — это JavaScript-библиотека для создания пользовательских интерфейсов. Именно библиотека, потому что она в первую очередь отвечает за отображение UI, а роутинг, работу с серверными данными и другие задачи можно решать отдельными инструментами.

Главные идеи — **компонентность, декларативность и однонаправленный поток данных**. Интерфейс собирается из компонентов, а вместо ручного изменения DOM мы описываем, как он должен выглядеть при текущих props и state.

Когда состояние меняется, React заново вызывает нужные компоненты, сравнивает новое описание интерфейса с предыдущим и применяет необходимые изменения. При этом React не заменяет весь DOM целиком.
