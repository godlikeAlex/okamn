`key` помогает React сопоставлять соседние элементы между рендерами. Ключ должен быть стабильным и уникальным среди элементов одного списка — обычно это ID из данных.

Без подходящих ключей React ориентируется на позицию. При вставке, удалении или сортировке индекс меняется, и состояние может сохраниться не у того элемента. Поэтому индекс подходит только для действительно статичного списка.

Идентичность компонента определяется его типом, позицией в дереве и key. Если key изменился, React не просто перерисует компонент, а размонтирует старый и создаст новый со сброшенным состоянием.

Иногда это используют намеренно, например чтобы сбросить форму при выборе другого клиента. Сам `key` внутрь компонента как prop не передаётся.
