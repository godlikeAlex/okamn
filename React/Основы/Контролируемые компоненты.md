Разница в источнике истины. В контролируемом поле значение хранится в React state: компонент передаёт `value`, а в `onChange` обновляет состояние. React полностью управляет тем, что показано в input.

Это удобно для зависимой валидации, масок, условного UI и синхронизации нескольких полей, но каждое изменение вызывает обновление состояния и рендер.

У неконтролируемого поля текущее значение хранит DOM. React задаёт `defaultValue`, а данные читаются через ref или `FormData` в нужный момент. Файловый input всегда остаётся неконтролируемым.

Библиотеки вроде React Hook Form часто используют неконтролируемый подход, чтобы уменьшить количество подписок и рендеров в больших формах. Главное — не переключать одно поле между контролируемым и неконтролируемым режимами без причины.
