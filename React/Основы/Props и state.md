**Props** — входные данные компонента, которые передаёт родитель. Компонент не должен их изменять. **State** — собственная память компонента, которой React управляет через `useState` или `useReducer`.

И props, и state для конкретного рендера являются снимками. Их нельзя мутировать напрямую: для state вызывается setter, а изменение props инициирует родитель.

Данные обычно идут сверху вниз. Родитель передаёт значение ребёнку через props, а ребёнок сообщает о событии через callback. Такой однонаправленный поток делает источник изменений понятнее.

Если значение можно вычислить из текущих props и state, его обычно не нужно хранить отдельным состоянием — иначе появляются дублирование и рассинхронизация.
