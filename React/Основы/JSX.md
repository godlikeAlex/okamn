JSX — синтаксическое расширение JavaScript для описания интерфейса. Он похож на HTML, но внутри можно использовать JavaScript-выражения через фигурные скобки, передавать props и вкладывать компоненты.

Браузер JSX не понимает. Сборщик преобразует его в вызовы JSX runtime, которые создают React-элементы. Поэтому JSX — это не строка и не шаблон HTML.

Есть несколько отличий от HTML: используются `className` и camelCase-свойства, JavaScript-слова вроде `htmlFor`, а возвращаемые соседние элементы нужно обернуть общим родителем или Fragment.

Строковые значения React экранирует, поэтому обычная вставка данных через JSX защищает от HTML-инъекции. Опасность появляется при явном использовании `dangerouslySetInnerHTML`.
