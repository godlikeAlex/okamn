Portal позволяет отрендерить часть интерфейса в другом месте DOM через `createPortal`, сохранив её на прежнем месте в React-дереве. Обычно порталы используют для модальных окон, тултипов и выпадающих меню, которым мешают `overflow` или stacking context родителей.

Context и логика родительских компонентов продолжают работать. События из portal всплывают по **React-дереву**, а не по физическому DOM-дереву, поэтому родительский React-компонент может поймать клик из модалки.

Portal решает только место вставки DOM. Управление фокусом, блокировка фоновой страницы, возврат фокуса и доступность модального окна остаются ответственностью приложения.
