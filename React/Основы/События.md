Обработчик события в React передаётся функцией, например `onClick={handleClick}`, а не результатом её вызова. Имена событий записываются в camelCase.

React передаёт обработчику `SyntheticEvent` — объект с единым интерфейсом поверх браузерного события. Через `nativeEvent` можно получить исходное событие. Начиная с React 17 события больше не очищаются старым pooling-механизмом, поэтому сохранять их через `persist()` обычно не нужно.

События в основном всплывают по React-дереву. `preventDefault()` отменяет стандартное действие браузера, а `stopPropagation()` останавливает дальнейшее распространение.

Обработчик — правильное место для логики, вызванной действием пользователя. Вызванные в нём обновления состояния React обычно объединяет в один batch.
