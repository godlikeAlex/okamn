**Компонент** — функция или класс, который описывает часть интерфейса. React вызывает компонент и получает результат рендера.

**React-элемент** — обычный иммутабельный объект-описание: какой тип нужно отрендерить, с какими props и children. JSX создаёт именно такие элементы, а не DOM-узлы.

**React-нода** — более широкое понятие: всё, что React умеет отобразить. Это React-элемент, строка, число, массив нод, portal, а также `null`, `undefined` и boolean, которые ничего не рисуют.

То есть компонент создаёт элементы, элементы описывают интерфейс, а нодой может быть любой допустимый результат рендера.
