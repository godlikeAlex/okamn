**XSS** — это выполнение чужого JavaScript в контексте нашего сайта. Например, приложение вставило пользовательский HTML без безопасной обработки. Такой код получает права origin страницы и может читать доступные JavaScript данные, отправлять запросы от имени пользователя и менять интерфейс.

Основная защита — безопасно выводить пользовательские данные, не вставлять непроверенный HTML, ограничивать источники через Content Security Policy и не хранить критичные токены там, где их легко прочитать из JavaScript. `HttpOnly` защищает Cookie от чтения, но сам XSS не устраняет.

**CSRF** — когда другой сайт заставляет браузер авторизованного пользователя отправить нежелательный запрос. Атака возможна, потому что Cookie могут прикладываться автоматически. Защита — `SameSite`, CSRF-токены, проверка `Origin` и отказ от изменяющих операций через `GET`.

Разница в том, что при XSS вредоносный код выполняется внутри нашего origin, а при CSRF запрос инициируется с чужой страницы, но использует автоматически приложенную авторизацию.
