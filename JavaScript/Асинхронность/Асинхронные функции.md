`async/await` — это синтаксис для работы с Promise. Любая `async`-функция всегда возвращает Promise: обычное возвращённое значение становится успешным результатом, а выброшенная ошибка — отклонением.

Когда выполнение доходит до `await`, JavaScript приводит выражение к Promise и приостанавливает только текущую `async`-функцию. Call Stack и основной поток не блокируются. После завершения ожидаемой операции продолжение функции ставится в очередь microtasks.

Ошибку ожидаемого Promise можно поймать обычным `try/catch`. Несколько последовательных `await` удобны, когда операции зависят друг от друга, но для независимых запросов это может случайно замедлить код.
