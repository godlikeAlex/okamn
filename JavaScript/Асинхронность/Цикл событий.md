JavaScript выполняет код в основном потоке через **Call Stack**.  
Синхронные функции кладутся в стек и выполняются по принципу LIFO.  
Асинхронные операции вроде `setTimeout`, запросов к серверу и DOM-событий обслуживаются средой браузера, **Web API**. Когда операция готова, её callback ставится в соответствующую очередь:
- Callback-и таймеров и событий попадают в **Task Queue**
- Promise-ы, `queueMicrotask` и `await` — в **Microtask Queue**.
  
**Event Loop постоянно проверяет состояние Call Stack.** Когда стек пуст, после завершения текущей задачи сначала полностью выполняются все задачи из **Microtask Queue**: каждая microtask по очереди попадает в **Call Stack**, выполняется и удаляется из него. Когда Microtask Queue становится пустой, браузер при необходимости может выполнить rendering.

Перед rendering выполняются callback-и `requestAnimationFrame`. Этот API используется для анимаций и визуальных обновлений, которые должны произойти перед отрисовкой следующего кадра.

После rendering, если до следующего кадра остаётся свободное время, браузер может выполнить callback `requestIdleCallback`. Он используется для фоновых задач с низким приоритетом.

После этого Event Loop берёт следующую задачу из **Task Queue**, помещает её callback в **Stack** и выполняет. После завершения этой task снова полностью очищается Microtask Queue, затем снова возможен rendering, и цикл повторяется.
