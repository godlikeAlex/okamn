Call Stack — это стек вызовов JavaScript. Когда вызывается функция, создаётся её stack frame с аргументами, локальными переменными и местом возврата и кладётся наверх стека. Если функция вызывает другую, сверху появляется новый frame. После завершения функции её frame снимается, и выполнение возвращается в предыдущую.

Стек работает по принципу LIFO: последняя вызванная функция завершается первой. Пока стек занят долгим синхронным кодом, браузер не может обработать следующую задачу, поэтому интерфейс может зависнуть.

### Почему возникает Stack Overflow?

Если функции продолжают добавляться в Call Stack и не завершаются, например при бесконечной рекурсии, стек переполняется и движок выбрасывает ошибку вроде `Maximum call stack size exceeded`.
