Область видимости определяет, где доступна переменная. В JavaScript есть глобальная, модульная, функциональная и блочная области. Они задаются **лексически**, то есть местом объявления в коде, а не местом вызова функции.

При поиске переменной движок сначала смотрит в текущем окружении, затем идёт по ссылкам во внешние окружения вплоть до глобального. Это называется цепочкой областей видимости.

Temporal Dead Zone — участок от начала блока до строки инициализации `let`, `const` или `class`. Привязка уже создана, но обращаться к ней нельзя — будет `ReferenceError`. Это касается даже `typeof`, который для переменной в TDZ тоже выбросит ошибку.
