В JavaScript всё передаётся **по значению**. Разница в том, что у примитива этим значением являются сами данные, а у объекта — ссылка на объект.

Если присвоить объект другой переменной или передать его в функцию, копируется ссылка. Поэтому изменение свойства через одну переменную будет видно через другую. Но если внутри функции присвоить параметру новый объект, внешняя переменная не изменится: мы заменим только локальную копию ссылки.

Примитивы сравниваются по значению, а объекты — по ссылке. Поэтому два отдельно созданных объекта с одинаковыми свойствами не равны, а две переменные, указывающие на один объект, равны.
