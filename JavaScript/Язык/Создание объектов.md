При вызове функции через `new` JavaScript создаёт новый объект, связывает его прототип с `Constructor.prototype`, вызывает конструктор с новым объектом в качестве `this` и обычно возвращает этот объект. Если конструктор явно вернёт другой объект, результатом станет он.

`class` даёт более удобный синтаксис для той же прототипной модели: `constructor` инициализирует экземпляр, методы попадают в прототип, а `extends` и `super` настраивают наследование.

При этом классы работают в strict mode, их нельзя вызвать без `new`, а до объявления они находятся в TDZ. Для скрытых полей существует синтаксис `#field`, доступный только внутри класса.
