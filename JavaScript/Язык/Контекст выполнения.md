Контекст выполнения — это внутреннее окружение, в котором JavaScript выполняет код. При запуске скрипта создаётся глобальный контекст, а при каждом вызове функции — новый функциональный контекст.

В нём хранятся параметры и локальные переменные, значение `this` и ссылка на внешнее лексическое окружение. Лексическое окружение состоит из собственных привязок и ссылки `outer`, по которой движок ищет переменные выше.

Создание контекста условно можно разделить на подготовку и выполнение: сначала регистрируются объявления, затем код исполняется строка за строкой. Активные контексты образуют Call Stack, поэтому после завершения функции выполнение возвращается в предыдущий контекст.
