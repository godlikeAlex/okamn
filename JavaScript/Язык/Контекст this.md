`this` — это специальное значение, которое у обычной функции определяется **в момент вызова**, а не в момент объявления.

Основные правила по приоритету:

- при вызове через `new` `this` указывает на создаваемый объект;
- при явной привязке через `call`, `apply` или `bind` используется переданный объект;
- при вызове `obj.method()` `this` — объект перед точкой;
- при обычном вызове это `undefined` в strict mode или глобальный объект без него.

У стрелочной функции собственного `this` нет — она берёт его из внешнего лексического окружения. Классическая проблема — потеря контекста, когда метод объекта передают как отдельный callback.
