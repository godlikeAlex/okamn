В JavaScript восемь типов данных: семь примитивных — `string`, `number`, `bigint`, `boolean`, `symbol`, `null`, `undefined` — и объектный тип. Массивы, функции, `Date`, `Map` и другие сложные структуры относятся к объектам.

Примитивы иммутабельны и представляют само значение. Объекты изменяемы, а переменная хранит ссылку на объект. При обращении к методу примитива JavaScript временно даёт доступ к объекту-обёртке, поэтому у строки можно вызвать, например, `toUpperCase()`.

`typeof` хорошо различает большинство примитивов, но у него есть исторические особенности: `typeof null` возвращает `"object"`, для массивов тоже получится `"object"`, а для функций — `"function"`. Поэтому массив проверяют через `Array.isArray()`.

`undefined` обычно означает, что значение не было присвоено, а `null` — что отсутствие значения задано явно. `NaN` означает некорректный числовой результат, но его тип — `number`; надёжно проверить его можно через `Number.isNaN()`.
