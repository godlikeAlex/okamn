`Map` — коллекция ключ-значение. В отличие от обычного объекта, ключом может быть значение любого типа, включая объект. `Map` сохраняет порядок добавления и имеет удобные методы `set`, `get`, `has`, `delete` и свойство `size`.

У обычного объекта ключи — строки и `Symbol`, есть цепочка прототипов, а сам объект чаще используют для описания сущности с заранее известными полями. `Map` удобнее как динамический словарь с частыми добавлениями и удалениями.

`Set` хранит уникальные значения и тоже сохраняет порядок добавления. Его часто используют для удаления дублей и быстрой проверки наличия значения через `has()`.
