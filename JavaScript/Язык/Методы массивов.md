Методы массивов удобно разделять на изменяющие исходный массив и возвращающие новое значение.

`push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse` и `fill` мутируют массив. `map`, `filter`, `slice`, `concat`, `flat` и `flatMap` создают новый массив. Современные `toSorted`, `toReversed` и `toSpliced` дают немутирующие аналоги сортировки, разворота и `splice`.

`map` используется для преобразования каждого элемента, `filter` — для отбора, `find` — для поиска одного элемента, `some` и `every` — для проверки условия, а `reduce` — для сведения массива к одному результату. `forEach` просто выполняет callback и всегда возвращает `undefined`.

Нужно помнить, что новый массив не означает глубокую копию: объекты внутри обычно остаются теми же ссылками.
