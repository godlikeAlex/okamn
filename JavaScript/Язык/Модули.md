ES-модули позволяют разделять код через `export` и `import`. Обычные импорты статичны: они анализируются до выполнения модуля и должны находиться на верхнем уровне. Благодаря этому сборщик может заранее построить граф зависимостей и удалить неиспользуемые экспорты через tree shaking.

Модуль выполняется в strict mode и только один раз, даже если его импортировали в нескольких местах. Импортированные значения — это живые привязки: если экспортирующий модуль изменит значение, импорт увидит обновление, но напрямую переприсвоить импорт нельзя.

`import()` работает динамически и возвращает Promise. Его используют для загрузки модуля по условию и code splitting. В отличие от CommonJS с `require`, ESM изначально спроектирован так, чтобы его структуру можно было анализировать статически.
