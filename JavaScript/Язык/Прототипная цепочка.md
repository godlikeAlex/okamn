У каждого обычного объекта есть внутреннее свойство `[[Prototype]]`, которое ссылается на другой объект или `null`. Когда JavaScript не находит свойство в самом объекте, он ищет его в прототипе, затем в прототипе прототипа и так далее до конца цепочки.

Если добавить объекту собственное свойство с тем же именем, оно перекроет свойство из прототипа. Проверить только собственное свойство можно через `Object.hasOwn()`.

У функций-конструкторов есть обычное свойство `prototype`. При вызове через `new` оно становится `[[Prototype]]` нового объекта. Синтаксис `class` тоже построен поверх этой прототипной модели: методы класса находятся в прототипе и разделяются между экземплярами.
