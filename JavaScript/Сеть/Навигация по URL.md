Сначала браузер разбирает URL: определяет протокол, хост, порт, путь и проверяет, нельзя ли получить страницу из кеша или через Service Worker.

Если нужен сервер, браузер определяет IP-адрес через DNS-кеши и DNS-резолвер. Затем устанавливается соединение: для HTTP/1.1 и HTTP/2 — TCP, а для HTTPS поверх него выполняется TLS-handshake с проверкой сертификата. HTTP/3 использует QUIC поверх UDP.

После этого браузер отправляет HTTP-запрос и получает статус, заголовки и тело ответа. Возможны редиректы, повторное использование соединения и получение ресурсов из кеша.

HTML постепенно парсится в DOM, CSS — в CSSOM. Браузер загружает связанные стили, скрипты, шрифты и изображения, строит render tree, выполняет layout, paint и compositing.

После загрузки JavaScript запускается приложение. В SPA интерфейс может полностью строиться на клиенте, а для страницы, отрендеренной на сервере, React выполняет hydration и подключает интерактивность к готовой разметке.
