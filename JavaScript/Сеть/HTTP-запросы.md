`fetch` — браузерный API для HTTP-запросов. Он принимает URL и настройки и возвращает Promise с объектом `Response`.

Важная особенность: ответы с HTTP-кодами 404 или 500 **не отклоняют Promise**. `fetch` завершится с ошибкой при проблеме на уровне сети, нарушении CORS или отмене запроса, а HTTP-статус обычно проверяют через `response.ok` или `response.status`.

Тело ответа читается отдельно через `response.json()`, `text()`, `blob()` и другие методы. Это поток, поэтому обычное тело можно прочитать только один раз; если нужны две независимые копии, используют `response.clone()`.

Для отправки Cookie на другой origin нужно явно указать `credentials: "include"`, а сервер должен разрешить credentials в CORS. Отменить запрос можно через `AbortController`, передав его `signal`.
