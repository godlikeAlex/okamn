`GET` получает ресурс, `POST` обычно создаёт ресурс или запускает действие, `PUT` полностью заменяет ресурс по известному адресу, `PATCH` изменяет его частично, а `DELETE` удаляет.

`GET` и `HEAD` считаются безопасными: по смыслу они не должны менять состояние сервера. Идемпотентность означает, что несколько одинаковых запросов имеют тот же итоговый эффект для состояния сервера, что и один.

`GET`, `PUT` и `DELETE` идемпотентны по семантике HTTP. Например, повторное удаление может вернуть другой статус, но ресурс всё равно останется удалённым. `POST` и `PATCH` в общем случае неидемпотентны, хотя конкретный API может сделать их такими, например через idempotency key.
