Access Token используется для доступа к API и обычно живёт недолго. Refresh Token живёт дольше и позволяет получить новую пару токенов без повторного входа пользователя. Из-за большего срока жизни refresh-токен хранят и обрабатывают осторожнее, часто в `HttpOnly Secure` Cookie.

JWT — это не назначение токена, а формат. Он состоит из `header.payload.signature`. В payload находятся claims, например ID пользователя, роли и срок действия. Подпись позволяет проверить, что данные не были изменены.

Обычный JWT **подписан, но не зашифрован**, поэтому секреты в payload класть нельзя. Сервер всё равно должен проверять подпись, срок действия, issuer, audience и другие нужные claims.

Access Token сложно мгновенно отозвать без дополнительного серверного состояния, поэтому ему дают короткий срок жизни. Для refresh-токенов используют ротацию: после обновления старый токен становится недействительным, что помогает обнаруживать повторное использование украденного токена.
