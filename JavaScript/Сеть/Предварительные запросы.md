Preflight — это предварительный запрос `OPTIONS`, которым браузер спрашивает сервер, разрешён ли будущий cross-origin запрос. В нём передаются планируемый HTTP-метод и нестандартные заголовки.

Он нужен не для каждого CORS-запроса. Простые запросы с разрешёнными методами и заголовками могут отправляться сразу. Например, `PUT`, `DELETE`, `Content-Type: application/json` или собственный заголовок обычно вызывают preflight.

Сервер отвечает заголовками `Access-Control-Allow-Origin`, `Access-Control-Allow-Methods` и `Access-Control-Allow-Headers`. Только после успешной проверки браузер отправляет основной запрос. Результат preflight можно кешировать через `Access-Control-Max-Age`.
